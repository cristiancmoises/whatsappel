# RC8 engineering brief: contact selection must remain usable

Inspect the exact retained RC7 source before changing behavior. The operator reports
an Emacs freeze while selecting a recipient. Do not claim a proven live root cause
without its stack trace or reproduction on that installation. Address concrete
blocking paths that can be identified in the provided code.

Make selecting a contact display a writable composer before refresh work. Do not
perform network requests, key-file probes, synchronous verification, image decoding,
or cached-history expansion inside the selection command. Discard deferred work
when its buffer, generation, account or selected window no longer matches.

Bound initial message/caption/sender rendering while preserving original records
for copying and an explicit paged reader. Reuse ready image specifications but
never start decoders inside message insertion. Decode at most one ready visible
preview per timer callback. Do not force redisplay from scrolling callbacks or
reschedule an already-expired idle timer.

Render encrypted messages using cached plaintext or an explicit Decrypt button.
Run pqenv only on explicit action, asynchronously with one owned child per chat,
stdin/argument separation, output/deadline bounds, unchanged signature/freshness
validation, no automatic retry, cleanup, scoped caches and late-result rejection.
Keep Org capture consistent with that cache. No new cryptographic guarantee.

Add native ERT coverage for selection ordering, rapid switching, stale contexts,
large text, unchanged drafts, hidden/visible previews and process cleanup. Include
an actual delayed loopback HTTP + Python-worker responsiveness test and distinguish
fake-verifier plumbing tests from real cryptography. Static checks do not count as
native execution. Execute the full audit twice on identical code and report missing
runtimes as blocked, not passes.

Deliver cumulative content-anchored source/update, review patch, EN/PT-BR guide,
exact evidence, and the existing guarded Guix update command. No forced replacement,
validation bypass, production deployment, remote push or real message. Include a
content-free diagnostic to identify the loaded version/path; describe a manual
C-g backtrace capture only when a freeze remains, with a privacy warning.
